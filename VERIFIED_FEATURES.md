# TaskBoard Pro Verified Features

The following claims are supported by the included source, documentation or configuration at the packaged commit.

## Verified

- Board, table, gallery and calendar view types are represented in the web app source.
- Cards, boards and board views are present in the source model.
- Filtering, sorting, grouping and display controls are present in the view header implementation.
- Card templates are present in the new-card workflow.
- Docker image and Docker Compose setup paths are present in the repository.
- The application is based on Mattermost Focalboard.

## Qualified

- Self-hosting is supported only to the extent provided by the included Docker configuration and upstream source.
- Import or migration references should be treated as upstream Focalboard help links, not as a verified active integration guarantee.
- Production use requires buyer-managed infrastructure, configuration, backups and security review.

## Not verified or removed

- Built-in time tracking.
- Native GitHub or Jira two-way integrations.
- 15-minute guaranteed setup.
- Lifetime updates.
- Priority support.
- Replacement of a full SaaS project-management stack.
- Blanket MIT licensing of all included source.
