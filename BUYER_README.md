# TaskBoard Pro Buyer README

TaskBoard Pro is a Velocity11-branded source package based on the open-source Focalboard project by Mattermost. It is intended for technically capable buyers who want to inspect, self-host, or adapt a kanban-style project and task management application.

## What is included

- Source code from the Velocity11 TaskBoard Pro fork.
- Original upstream licence files and notices from Focalboard/Mattermost.
- Velocity11 buyer documentation in `BUYER_DOCS/`.
- Setup guidance for Docker-based self-hosting and source inspection.

## What this package is not

- It is not a hosted SaaS account.
- It is not a managed deployment service.
- It is not a promise of custom integrations, future updates, or unlimited support.
- It is not newly relicensed by Velocity11 under a blanket MIT licence.

## Recommended first steps

1. Read `BUYER_DOCS/VERSION_INFO.txt`.
2. Read the original `LICENSE.txt` and `NOTICE.txt` files.
3. Review `BUYER_DOCS/SETUP_GUIDE.md`.
4. Inspect `BUYER_DOCS/VERIFIED_FEATURES.md` before relying on any advertised feature.

## Support

Support is limited to the packaged files and documentation. See `BUYER_DOCS/SUPPORT_BOUNDARIES.md`.
